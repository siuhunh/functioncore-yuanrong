# 支持设置用户环境变量并加解密

关联AR:
+ AR-20210630-006-001

## Story 整体设计

### 功能描述
1. 需求场景

   提供给用户配置全局变量值的能力。例如：配置文件的路径，图片输出地址等变量值，用户并不期望在代码里面在去配置相关信息，所以提供全局配置的能力就显得尤为重要。

2. 应用场景：

   1. 用户在界面上可以选择加密配置和非加密配置，其中加密配置的变量值只写入context，非加密配置的变量值会写入runtime环境变量。
   2. 写入context的变量，通过 context.getUserData(key) 获取key对应的value
   3. 写入runtime环境变量的，可以通过java，nodejs，python对应的os获取。
      1. java: System.getenv().get(key)
      2. nodejs: process.env.key
      3. python: os.environ[key],需要导入

3. 安全性：

   1. 需求相关，在后端实现加密存储。无论是加密配置还是非加密配置的变量，在后台存储都是加密的，防止用户写入隐私数据后被明文存储。

### 场景分析
1. 存储场景分析：

   ![](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/qey?t=1623987988696)

2. pod特化阶段：

   worker会加载函数信息，通过rpc与runtime建立通信连接。

   加载函数调用FetchEnvFromConfig，在这个阶段会写入预留字段信息，同时会将函数元信息里携带的用户环境变量信息进行解密，传入runtime，后写入context和runtime环境变量。


### 方案详细设计

#### 方案设计
1. 见场景分析存储设计

   1. functiongraph接收用户的函数保存操作，将携带的函数信息通过管理面组件写入etcd，其中环境变量相关信息写入如下字段：

      ```go
      "envMetaData":{
          "environment": "加密后的用户环境变量",
          "encrypted_user_data": "加密后的用户环境变量"
      }
      ```

   2. 对齐相关字段，在元戎基础上增加encryptedUserData字段，设计组件或模块代码：

      common, functiontask, workermanager, worker

      ```go
      envKey string
      envInfo string
      encryptedUserData string
      ```

      

   3. rpc字段增加runtimeEnvs

      ```go
      message LoadRequest {
          // file name of entry function
          string entry = 1;
          // entry function name
          string funcName = 2;
          // env of user function
          repeated string funcEnvs = 3;
          // env of runtime
          repeated string runtimeEnvs = 4;
      }
      ```

      funcEnvs内的内容在runtime写入context

      runtimeEnvs的内容写入环境变量

2. 解密算法适配

   1. 卓然已经同步了graph的解密算法，复用即可

3. 预留字段写入：

   1. [预留字段清单](https://clouddevops.huawei.com/domains/551/wiki/8/WIKI2021060100114)

4. runtime通过rpc接收worker传过来的数据信息，进行信息写入

   1. funcEnvs字段内容写入context的envMap；
   2. runtimeEnvs的字段内容写入对应的os
      1. java，通过反射往System里面设置；
      2. nodejs, 往内置的process.env内放置；
      3. python，往os.environ里面放置。
