# AR-20210630-011-001-支持租户独占vm模式（大客户函数）

AR： AR-20210630-011-001

## 1. Story 整体设计

### 1.1 功能描述

数据面根据给定的标签，找到符合的节点，部署大客户函数。

**背景：**出于安全性考虑，大客户函数需要独占 vm，以保障大客户数据安全，防止数据被其他普通函数获取。

**前提：**

1.大客户所有函数都要部署到独占 vm 上，普通函数不会部署到大客户独占的 vm 上

2.一个独占 vm 上只包含一个大客户的函数，不存在一个独占 vm 上有两个大客户函数的情况

3.所有的节点都被打上标签

其中，普通节点的标签为 `node-role=data-plane`

大客户节点的标签为 `tenant_id: 7e1ad6a6cc5c44fabd5425873f72a86a`

### 1.2 场景分析

**正常场景：**

1. 函数预留实例部署到指定节点

   通过在函数元信息中加入 label 标签的方式，实现函数预留实例部署到指定节点上。

2. 函数部署调用到指定节点：

   函数调用时，从函数元信息中获取 label 标签信息，实现函数部署调用到指定节点上。

**异常场景：**

1. 预留实例部署时，找不到指定标签的可用节点

   预留实例部署时，如果找不到指定标签的可用节点，则预留实例部署失败。不影响后续函数调用。

2. 函数部署调用时，找不到指定标签的可用节点

   函数部署调用时，如果找不到指定标签的可用节点，按照已有代码逻辑，会重试 3 次，每次间隔 1s，失败返回错误。

### 1.3 方案详细设计

[AR-20210630-011-001 支持租户独占vm模式（大客户函数）-Open Model](https://cloudmodeling.tools.huawei.com/projectspace/detail/2928afd8ae624e609af7b0148bf05fad?projectDiagramUUID=b74a66bd76e840d5a06523e6137cbba1&versionUUID=)![AR-20210630-011-001 支持租户独占vm模式（大客户函数）](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/xox?t=1628752796260)

一、函数预留实例部署到指定节点

在函数元信息的 extendedMetaData 字段中，加入 user_type 字段，定义函数为 vip 函数。

function instance manager 模块 watch 到 etcd 中函数元信息时，读取 user_type 字段，写入 CR 中；

function instance manager 模块 watch 到 CR 信息发生变化，读取 user_type 字段，根据 tenantID 找到指定节点，拉起最小实例。

二、函数部署调用到指定节点

函数调用时，读取 CR 信息中的 user_type 字段

function instance manager 模块解析 user_type 字段后，结合 tenantID，找到满足此标签的节点，拉起函数实例。

### 1.5 对齐和管理面对接的数据格式

管理面需要：

1）给所有节点打上标签

其中，普通节点的标签为 `node-role=data-plane`

大客户节点的标签为 `tenant_id: 7e1ad6a6cc5c44fabd5425873f72a86a`

2）修改 etcd 里面的函数元数据信息，在 extendedMetaData 字段中新增 user_type 字段；

和管理面交互的接口：

```json
// vip 函数
"extendedMetaData": {
    "user_type": "vip" // 新增字段
}
// 普通函数这个字段为空
```
