# AR.20210621221420.025 支持函数配置调用链能力（JAVA）

## Story 整体设计

### 功能描述
**背景说明**  
支持函数配置调用链能力数据面能力开发，使调用链能力能够完整端到端进行展示
**功能描述**  
用户在函数界面进行函数调用后，能够在调用链界面看到相关信息
**用户体验**  
用户可以看到函数加载信息、初始化信息等

### 场景分析
调用链能力的端到端体验需要管理面、数据面、依赖包共同完成
- 管理面：写入AK\SK\projectName至ETCD中的函数元数据信息中 -- 潘炜程
- 数据面：感知到函数元信息的写入，将其作为特化信息传递至worker -- 丁震
- 依赖包：apm-agent的jar包开发 -- 张祖帆


### 方案详细设计

数据流图 ![数据流图](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/11zd)

#### 方案设计
1. 调用链的需求需要在pool池化时即加载依赖包，需将java进程的启动参数做成可配置，并指定javaagent目录为调用链插件所在目录

2. 插件apm-agent需要在池化时即进行加载，因此需要打入runtime-manager镜像之中

3. 插件会监听特化函数loadfunction，因此需要在调用该接口函数之前，完成函数加载时间统计、特化信息收集，并在调用时通过环境变量传递

4. 环境变量中时间统计信息：func-FAAS_LOAD_TIME
   AK：func-FAAS_TRACE_AK
   SK：func-FAAS_TRACE_SK
   ProjectName：func-FAAS_PROJECT_NAME

5. 插件打入runtime-manager镜像中的配置文件不包含master.address、log.path这两个重要的配置信息，因此需要元戎数据面在加载插件之前将相应信息写入，log.path指定为/tmp目录

6. worker的config中在runtime-manager-config的java部分增加customArgs、traceMasterAddress，该两配置默认均不填写。

#### 外部交互分析&&上下游依赖需求
写入AK\SK\projectName至ETCD中的函数元数据信息中 -- 潘炜程
apm-agent的jar包开发 -- 张祖帆
