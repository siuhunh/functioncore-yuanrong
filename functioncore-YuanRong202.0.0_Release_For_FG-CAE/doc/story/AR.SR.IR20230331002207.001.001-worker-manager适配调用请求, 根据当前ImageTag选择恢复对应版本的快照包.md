# Worker-manager适配调用请求

## 1. 需求场景分析

### 1.1 特性需求来源与价值概述

解决因runtime-java升级后导致快照失效的问题

主要包含1个AR：

- AR.SR.IR20230331002207.001.001  【functioncore】worker-manager适配调用请求, 根据当前ImageTag选择恢复对应版本的快照包

### 1.2特性场景分析

*描述该特性的业务使用场景内容包括：*

1. 升级场景下

   (1）*Runtime-java框架升级场景*

   升级过程中，存在旧版本快照和新版本快照，worker-manager需根据imageTage选出正确的快照

   (2）*Runtime-java框架非升级场景*

   Runtime-java非升级场景下，只存在一种快照，无需选择

2. 回退场景下同上


## 2. 特性/功能实现原理

### 2.1总体方案

##### 2.1.1.1 设计目标

升级或回退场景下，worker-manager适配并兼容新旧快照，保证平滑升级

##### 2.1.1.2 设计原理

worker-manager接受调用请求，获取正确的imageTage后，根据imageTage选择正确版本的快照信息，并覆写到函数元数据里，转发给worker去恢复对应版本的快照包

1. 获取环境变量RUNTIME_MANAGAER_TAG值作为imageTage

2. 根据imageTage在元数据拓展的快照信息中选择正确的快照信息

3. 覆写转发给worker的快照信息
