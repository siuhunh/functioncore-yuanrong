【functionCore】【可容灾】数据面redis应急恢复

## 1. Story整体设计

### 1. 功能描述
数据面使用的redis在崩溃等异常情况下，如何快速恢复，保证数据面正常。

### 2. 场景分析
当前数据面使用redis的组件只有Function Instance Manager, 用于上报函数实例个数指标和初始化异常计费信息，如果redis异常会导致指标指标数据和异常计费缺失。
所以当redis出现异常导致无法访问时，需应急恢复，保证指标数据和异常计费上报正常。
		
### 3. 方案详细设计
当前redis使用的是华为云DCS，购买的实例是主备实例

#### 主节点故障
主节点故障，会自动发生主备倒换，保证DCS服务正常，但是需要确认客户端业务是否存在异常。

主备实例发生主备倒换后是否需要客户端切换IP？
不需要。当主备倒换或主节点故障后，IP地址会自动绑定到正常的备节点，绑定后，原备节点升级为主节点。

主备倒换有3种可能场景：
1. 用户自行从DCS控制台界面发起“主备倒换”操作，切换主实例。
2. DCS检测到主备实例的主节点存在故障后，触发实例“主备倒换”操作。
3. 例如，使用了keys等消耗资源的命令、日志老化批量删除日志，导致CPU超高，都会触发主备倒换。

用户在DCS界面上执行重启操作，可能触发备节点升主节点，即主备倒换。
发生主备倒换后，系统会上报主备倒换事件，收到该事件通知后，请查看客户端业务否存在异常，如果业务不正常，
则需要确认客户端tcp连接是否正常，是否支持在主备倒换后重新建立tcp连接恢复业务。（需确认）

#### 主备节点全部故障
主备节点全部故障，通过创建新实例迁移数据的方式快速恢复，减少中断。

所以需要备份缓存数据，当前华为云DCS支持备份缓存数据，备份方式支持定时备份和手动备份。

##### 定时备份
您可以通过管理控制台设置一个定时自动备份策略，在指定时间点将实例的缓存数据自动备份存储。

定时备份频率以天为单位，您根据需要，选择每周备份一次或多次。备份数据保留最多7天，过期后系统自动删除。

定时备份主要目的在于让实例始终拥有一个完整的数据副本，在必要时可以及时恢复实例数据，保证业务稳定，实例数据安全多一重保障。

##### 手动备份
除了定时备份，DCS还支持由用户手动发起备份请求，将实例当前缓存数据进行备份，并永久性存储到OBS服务中（您可根据需要手动删除备份数据）。

您在执行业务系统维护、升级等高危操作前，可以先行备份实例缓存数据。

##### 备份文件的存储与收费
备份文件存储在对象存储服务（OBS）中。
DCS不收取备份费用，仅OBS会根据存储空间占用和存储时长，按统一标准收取一定费用。

##### 创建新实例迁移数据
此操作相当于实例数据迁移，首先购买新的redis实例，然后创建OBS桶并上传备份文件，最后创建迁移任务，等待迁移任务执行成功。

注：
1. 使用了新的redis实例，redis的IP地址发生变化，需修改function instance manager的configmap中redis的地址，并重启workermanager实例。
2. 使用了新的redis实例，redis的IP地址发生变化，需修改管理面的funcmonitor的redis配置，并重启该实例。
3. 当前redis存储的是指标和计费数据，funcmonitor采集后立即删除，所以只是个传输数据通道，所以备份数据是否有必要？
