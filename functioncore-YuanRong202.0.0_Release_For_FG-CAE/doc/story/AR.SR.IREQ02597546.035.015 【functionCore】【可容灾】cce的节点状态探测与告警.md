# AR.SR.IREQ02597546.035.015 【functionCore】【可容灾】cce的节点状态探测与告警


## Story 整体设计

### 功能描述
从业务层面提升探测能力；
1. InstanceMgr 通过 k8s 监控 node 状态，异常则驱逐归属于该节点 proxy 的 worker
2. proxy daemonset 会自行向 etcd 续租，无法续租，则出现问题，frontend 停止路由到这个proxy。Proxy重启后恢复发送


### 场景分析
1. 节点下线后，清理节点管理的 worker  
InstanceMgr通过 k8s 监控 node 状态，异常则驱逐归属于该节点 proxy 的 worker

2. functiontask daemonset 校验当前节点 Pod 是否OK

### 方案详细设计

#### 方案设计
1. InstanceMgr 通过 k8s 监控 node 状态，异常则驱逐归属于该节点 proxy 的 worker  
节点下线后，清理节点管理的 worker  

2. proxy daemonset 会自行向 etcd 续租，无法续租，则出现问题，frontend 停止路由到这个proxy。Proxy 重启后恢复发送
当远程某个 functiontask 无法访问，不再往此节点实例调度请求，等恢复时在调度请求到此节点实例上  
（1）tcp通信失败：采用熔断恢复机制，3S恢复可用，如果再次TCP通信失败，再次熔断  
（2）functiontask 节点不可访问（etcd 中无此节点 functiontask 信息）: 不往此节点实例调度请求。等 etcd 中有此functiontask 节点信息，恢复此节点可用  
以上两个条件有一个不满足节点可用，就不往此节点实例调度请求。
