# AR.SR.IREQ02597546.035.027-数据面支持亚健康检测，上报告警

## 1. Story 整体设计

### 1.1 功能描述

为了保证数据面服务可用，及时感知集群、节点和pod的状态，对其重要信息进行监控

### 1.2 场景分析

1. 集群CPU和内存占用需要监控，设置低阈值重要告警，高阈值紧急告警
2. 节点系统盘状态需要监控
3. 节点SFS文件系统需要监控
4. 非池子的数据面pod状态如果有异常，需要告警

### 1.3 方案详细设计

- **告警规则** <br/>
  在CloudScope中配置告警规则如下：<br>

| 告警名称 | 告警级别 | 设置规则 |
| ---- | --------------- | ------------------  |
|  FunctionGraph数据面集群CPU85%告警 | 重要 | 监控集群CPU使用率，连续5次超过85%即告警 |
|  FunctionGraph数据面集群CPU95%告警 | 紧急 | 监控各节点CPU使用率，连续5次超过85%即告警 |
|  FunctionGraph数据面节点CPU95%告警 | 重要 | 监控各节点CPU使用率，连续5次超过95%即告警 |
|  FunctionGraph数据面集群内存85%告警 | 重要 | 监控集群CPU使用率，连续5次超过85%即告警 |
|  FunctionGraph数据面集群内存95%告警 | 紧急 | 监控各节点CPU使用率，连续5次超过85%即告警 |
|  FunctionGraph数据面节点内存95%告警 | 重要 | 监控各节点CPU使用率，连续5次超过95%即告警 |
|  FunctionGraph数据面节点磁盘80%告警 | 重要 | 监控节点磁盘使用率，1次超过80%即告警 |
|  FunctionGraph数据面节点SFS文件系统85%告警 | 重要 | 监控节点SFS文件系统使用率，1次超过85%即告警 |
|  FunctionGraph数据面FunctionAccessor状态告警 | 重要 | 监控FunctionAccessor的容器状态，有容器异常则触发告警 |
|  FunctionGraph数据面Functiontask状态告警 | 重要 | 监控Functiontask的容器状态，有容器异常则触发告警 |
|  FunctionGraph数据面FunctionInstanceManager状态告警 | 重要 | 监控FunctionInstanceManager的容器状态，有容器异常则触发告警 |
|  FunctionGraph数据面Cachemanager状态告警 | 重要 | 监控Cachemanager的容器状态，有容器异常则触发告警 |

- **告警级别** <br/>

| 级别 |     告警方式           |
| ---- | ------------------ |
| 紧急   | oncall人员收到电话，在cloudscope配置的组内所有人员收到短信 |
| 严重   | oncall人员收到短信 |
| 提示   | 系统记录 |

### 1.4 上下游依赖需求
与cloud scope管理人员对接，创建设计好的告警。对接人施广帅，刘东东
