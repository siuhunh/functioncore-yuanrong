# AR.SR.IREQ02597546.036.001 【functionCore】支持预留实例函数计费

## Story 整体设计

### 功能描述
**背景说明**  
为完善元戎数据面计费体系，需要针对预留实例功能单独新增计费逻辑，保证用户在创建预留实例后，能够对其进行计费。
**功能描述**  
当预留实例创建后，只要实例存在即存在资源占用的情况，此时计费开始，在此期间若预留实例被删除或异常退出，则计费结束。
**用户体验**  
用户创建的预留实例能够正常进行收费，且计费准确。

### 场景分析
预留实例计费的特性需要管理面适配对接，非数据面独立需求，需要数据面组件将预留实例的资源占用时间戳周期性写入redis，格式对齐后管理面负责读取计算并最终转化为计费结果

1、用户在函数界面创建预留实例，数据面感知创建操作后拉起预留实例，此时计费开始，在此资源占用未释放期间计费一直进行
2、用户在函数界面删除预留实例函数，数据面感知删除操作后删除预留实例，计费结束。
3、预留实例异常退出后会重新拉起，中断期间不进行计费。
4、instanceManager负责进行预留实例资源占用时间戳采集并负责上报，当前采用主备方式部署，若全部异常则计费信息会缺失

### 方案详细设计

#### 方案设计
1. 定时统计资源占用时长；时间间隔一分钟；统计 [periodStartTime, periodEndTime] 时间段内的资源占用时长，periodStartTime 为上一个统计周期的 periodEndTime，periodEndTime 为 nowTime;

2. 预留实例拉起时，会将创建时间戳写入；预留实例删除时，会将删除时间戳写入。

3. 定时统计函数会进行时间戳校验，若创建时间戳早于当前时间窗口，则以当前时间窗口开始时间为写入初始时间；若创建时间戳在当前时间窗口内，则以创建时间戳为准。

4. 若删除时间戳在当前时间窗口内，则以删除时间戳为准。

4. 预留实例创建时会为其添加label，在进行缩容时，预留实例原则上不会进行删除，普通实例会优先进行删除。

注：资源占用时长计费按秒级计费，上报时间戳单位为毫秒

5. instanceManager统计预留实例资源占用时长指标后，将其转换成json字符串，插入到 redis 的列表 ReservedInstancesFeeList

{ 
   "functionURN" ： "projectID@package@functionName@version@memSize",
   "podName" : "pool23-400-256-fusion-59bd9fb656-vfcl9",
   "timeWindows" : [{startTime, endTime}]
}

#### 外部交互分析&&上下游依赖需求
functionGraph 管理面 funcmonitor 组件采集上报到redis的资源占用时长数据（梁新宜）。
