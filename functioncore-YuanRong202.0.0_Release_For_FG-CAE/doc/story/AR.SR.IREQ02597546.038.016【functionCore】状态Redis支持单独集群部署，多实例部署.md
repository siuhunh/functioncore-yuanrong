【functionCore】状态Redis支持单独集群部署，多实例部署.md

## 1. Story整体设计

### 1. 功能描述
支持状态redis多az部署

### 2. 场景分析
当前redis使用华为云DCS，采用主备模式和多可用区实例（主节点和备节点分布在不同可用区）

1. DCS Redis 3.0已下线，建议使用Redis 5.0。
2. 目前采用一主一从。主 AZ 主节点，副AZ从节点。

### 3. 方案详细设计

#### 购买实例
-  登录[分布式缓存服务管理控制台](https://console.huaweicloud.com/dcs)，选择”购买缓存实例“。
- 版本号选择5.0，实例类型选择主备，选择副本数（包含主节点），主可用区和备可用区建议选择在不同可用区。
- 在“实例规格”区域，选择合适规格。
- 选择已经创建好的虚拟私有云。
- 设置访问密码。
- 选择购买时长和实例数，完成购买。

#### 变更规格

- 实例变更期间，连接会有秒级中断，大约1分钟的只读。建议在业务低峰期进行。

- 登录[分布式缓存服务管理控制台](https://console.huaweicloud.com/dcs)，选择”缓存管理“。在需要规格变更的实例右侧，单击“操作”栏下的“更多 > 变更规格”。
- 选择“容量变更”变更实例内存、最大连接数、带宽，选择“副本数变更”增加或删除实例副本。


### 4. 上下游依赖需求
redis部署与施广帅对接。
