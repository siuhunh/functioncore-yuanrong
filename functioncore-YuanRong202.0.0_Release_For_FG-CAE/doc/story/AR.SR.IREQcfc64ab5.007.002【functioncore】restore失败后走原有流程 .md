# restore失败后走原有流程

## 1. 需求场景分析

### 1.1 特性需求来源与价值概述

需求来源于问题单。当runtime版本进行升级后，进行快速启动会触发restore失败。restore失败后走非冷启动流程，保证restore失败后runtime能够正常启动。

主要包含1个AR：

- AR.SR.IREQcfc64ab5.007.002  【functioncore】restore失败后走原有流程

## 2. 特性/功能实现原理

### 2.1总体方案

##### 2.1.1.1 设计目标

restore失败后，正常模式启动runtime，预期冷启动不失败。

##### 2.1.1.2 设计原理

- runtimemanager检测runtime进程是否正常启动
- 检测runtime restore失败后，runtime manage以正常模式启动runtime process
- 在冷启场景下，restore 失败，worker与runtime建立连接失败后，重试连接
