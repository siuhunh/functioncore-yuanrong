# AR.SR.IREQf58c143d.003.005-functiontask组件升级加速

## 1. 需求场景分析

### 1.1 特性需求来源与价值概述

1.需求来源：数据面全网变更效率提升识别

2.价值概述：加快数据面升级速度，提高数据面升级效率

### 1.2特性场景分析

数据面切流升级的场景，加快functiontask升级速度：

functiontask 100%一起升级；还在functionbus中尚未下发的请求，可以立即返回。

## 2. 特性/功能实现原理

### 2.1总体方案

functiontask 100%一起升级。在functionbus中排队等待的请求和已经发入functionbus尚未入队也未下发的请求，立即返回请求响应。

### 2.2模块详细设计

1. 在functionbus中排队等待的请求，会在functionbus进入优雅退出状态之后，遍历所有的requestdispatcher，将队列中的请求全部返回error response，错误码211410（200500的情况，请看3.12 升级兼容性）
2. 已经发入functionbus的请求，还没来得及入队的，在步骤1执行过后，会因为识别到步骤1的标识位而立即返回211410，不再在升级集群中下发
3. functiontask升级从当前的50%滚动升级，改为直接100%升级，可以减少至多15min升级时间

### 2.3 约束

#### 2.3.1上下游依赖需求

完全依赖管理面换集群重试，返回的211410错误码在管理面重试白名单中

#### 2.3.2其他约束
