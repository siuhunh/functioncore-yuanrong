# 【common】元etcd节点使用的ntp_check服务新增上报NTP服务器状态、NTP同步状态告警

## Story 整体设计

### 

**背景说明**

问题单DTS2022090706686转需求，元etcd节点使用的ntp_check服务新增上报NTP服务器状态、NTP同步状态告警

**功能描述**

元etcd节点原先只涉及NTP的时间发生偏差时的告警，现在需要新增1个NTP服务器状态的告警，如果NTP服务器断开连接，ntp-server获取不到时间信息了，若干次数之后，将会上报告警信息

**用户体验**

当NTP服务器不可用的时候，运维人员会收到告警信息

### **场景分析**





### **方案详细设计**

#### 方案设计

使用NTP服务器常用的ticker计数器，每隔几秒会对NTP的服务状态发起一次检查，在检查时间偏差之前会先检查NTP服务器的健康状态，如果一次检查失败后，failedConnCnt失败连接次数会加1，失败到一定的次数后，设定为10次，会上报告警。
若服务器状态获取成功了，则会进行消警。上报告警的内容与之前的信息一致




#### 外部交互分析&&上下游依赖需求

告警信息将传至于OSMVC
