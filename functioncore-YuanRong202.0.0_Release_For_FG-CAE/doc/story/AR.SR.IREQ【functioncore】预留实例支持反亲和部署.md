# AR.SR.IREQ02793119.004.002【functioncore】预留实例支持反亲和部署

父需求

SR.IREQ02793119.004 【functioncore】系统可用性增强

IREQ02793119 【可信】元戎DFX能力增强

## 1. Story 整体设计

### 1.1 功能描述

**背景**

- 天眼查里由于预留实例规格比较大8192MB，一个节点上可能会部署2个函数预留实例，当请求压力增长太大，会导致时延超过指标
- 目标，尽量让一个节点上只部署一个天眼查的函数预留实例，尽量做到节点均分

### 1.2 详细设计

- 集群默认配置预留实例反亲和部署模式
- worker-manager的configMap中需要配置poolMgrConfig.reservedAntiAffinity （string类型、后面可拓展，可以支持弱反亲和与强反亲和） （false为关闭、weak为弱反亲和）
- poolmanager.PodRequest 通过增加 Applier、funcSvcID字段，感知要拉起的pod是否是预留实例，
  funcSvcID字段用来获取functionCache以此获取已经部署的预留实例所在的node，后续拉起的预留实例pod需要部署在其他还未部署
  该函数预留实例的node上
- poolmgr获取pool后，通过fcCache中instances的预留实例node分布与reservedInsNodeDis预分配map预计算pool中node的预留实例分布，得到1个map[string]int（key 为nodeIp，value为node上分布的预留实例数），选择预留实例数最小的节点，即为反亲和节点，（兜底措施为返回空列表，即随机选取；或是失败后会自动重试）使用choosePodfromNode选择pod。
