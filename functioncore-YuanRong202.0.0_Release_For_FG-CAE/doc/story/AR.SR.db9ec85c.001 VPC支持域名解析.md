# AR.SR.db9ec85c.001 VPC支持域名解析

## Story 整体设计

### 功能描述
**背景说明**  
v1版本函数配置界面支持在配置VPC时指定域名，v2版本不支持此功能
**功能描述**  
用户可以在函数配置界面指定域名
**用户体验**  
配置域名后的函数，可以在函数中访问该域名

### 场景分析
VPC域名解析的端到端体验需要管理面、数据面共同完成
- 管理面：前端界面新增域名配置界面，管理面完成域名解析并将解析后的IP传递至数据面 -- 郑亚林、龚湘忠
- 数据面：感知解析后的IP，修改worker的host内容 -- 丁震

#### 方案设计
1. 管理面感知域名配置后，将其解析成IP，在发送至数据面的请求中，通过headers传递该信息

2. IP信息通过frontend、bus-proxy、worker完成传递，最终由worker感知

3. worker若感知到该信息，则完成host修改

4. 由于该IP非固定不变，因此worker在修改的同时需要缓存该信息，再次收到请求时若IP发生变化则需重新修改host

### 对外接口
无
