# AR.SR.fb60c8f3.001 函数刷新支持语言版本：node.js 18 \ Python 3.10

## 1. Story整体设计

### 1. 功能描述

函数刷新支持语言版本：node.js 18 \ Python 3.10

### 2. 场景分析

用户创建函数能够选择node.js 18 \ Python 3.10，创建成功后能够测试函数并返回执行结果。
		

## 2. 特性/功能实现原理

### 2.1  具体实现

nodejs18长期支持版本：18.15.0

python3.10长期支持版本：3.10.0

1. fusion镜像安装nodejs 18.15、python3.10，安装目录/opt/function/runtime/nodejs18.15、/opt/function/runtime/python3.10，并安装默认集成的三方库：https://support.huaweicloud.com/usermanual-functiongraph/functiongraph_01_0391.html
2. worker模块新增注册 nodejs18.15、python3.10 runtime
3. nodejs runtime 模块新增nodejs 18.15执行分支, python runtime代码不需要修改

runtime提前启动调研
128规格池子：默认启动runtime为nodejs(10.16、12.13)、python3.6和Java8，加上 runtime-manager ，已占用内存为120MB左右，该规格不提前启动
256规格池子：默认启动runtime为nodejs(10.16、12.13、14.18)、python(3.6和3.9)、java(8和11)、php7.3，nodejs16，已占用内存为250MB左右，该规格不提前启动

暂时不做提前启动，等后续调用量上去再考虑

4. worker-manager deployment 环境变量 RUNTIME_MANAGER_CONFIG 新增配置如下：

```
   "nodejs18.15": {
        "port": 31549,
        "enable": false,
        "workerDir": "/opt/function"
   }
   "python3.10": {
        "port": 31550,
        "enable": false,
        "workerDir": "/opt/function"
   }
```
