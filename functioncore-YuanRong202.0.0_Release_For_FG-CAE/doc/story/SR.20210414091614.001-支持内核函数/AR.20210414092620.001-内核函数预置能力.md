# 内核函数预置能力

## Story 整体设计

### 功能描述
内核函数提供了FunctionCore的一些系统能力，FuncionCore部署同时就需要内核函数也部署完毕，而不是需要每次升级或者安装后，系统管理员再进行一次部署内核函数。



kernel-manager提供内核函数的预置能力，将预置的内核函数直接打入到kernel-manager镜像中，kernel-manager启动后自动完成内核函数的部署。

##### 内核函数目录结构

内核函数放置在kernel-manager的/home/kernelfunctions/目录下，每个函数一个目录，目录名称为函数名，目录下包含function.yaml文件和函数zip压缩包，如下所示：
```
├── cpphandler
│   ├── function.yaml
│   ├── cpphandler.zip
```


##### function.yaml

function.yaml描述的是内存信息等，预留了runtime，当前只支持c++，后续可扩展，实例如下：
```
 cppinvoke:
    handler: cppinvoke 
    runtime: cpp11
    memorySize: 500
    timeout: 900
```

##### 对接function-repo

对接repo的流程：

kernel-manager启动完成后开始内核函数的部署，遍历所有函数，每个函数做以下步骤

1、向repo查询该函数是否存在，不存在则调用创建API

2、已存在则调用update 的API
