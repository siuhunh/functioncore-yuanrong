# 【IPV6】元戎支持函数访问IPV6 网络

## 1. 需求场景分析

### 1.1 特性需求来源与价值概述

IPv6作为华为云重点工作进行推进，为满足工信部TOP30要求，同时对标AWS云服务的IPv4/IPv6双栈能力。华为云云服务有44个云服务需要满足IPv4/IPv6双栈能力，整体提升华为云IPv6竞争力。

### 1.2特性场景分析

1、需要支持用户函数对外的IPV6网络访问

2、数据面业务组件内部通信、与第三方服务的通信依然采用IPV4的网络模式

### 2.1总体方案

### 2.2模块详细设计

1、数据面集群重建，支持IPv6

- 网络模型：选择“容器隧道网络”。

- 虚拟私有云：选择已创建的“vpc-ipv6”。

- 控制节点子网：请务必选择已开启了IPv6的子网。

- IPv6双栈：选择开启，开启后将支持通过IPv6地址段访问集群资源，包括节点，工作负载等。

- 容器网段：容器网段要设置合理的掩码，掩码决定集群内可用节点数量。集群中容器网段掩码设置不合适，会导致集群实际可用的节点较少。

  ![img](https://support.huaweicloud.com/bestpractice-cce/zh-cn_image_0000001217540332.png)


2、worker增加ipv6路由，公网出口支持ipv6

- 数据面集群重建IPV6改造后，节点上启动的Pod默认支持公网出口IPV6。
- Pat支持IPv6隧道打通租户VPC，用户函数元数据信息中新增支持IPV6字段，由worker-manager感知，并在特化时传递给worker，worker在进行Pat网络打通时，在原有IPV4路由规则修改的基础上，新增IPV6路由规则修改。
- 域名解析需要适配IPV6场景
