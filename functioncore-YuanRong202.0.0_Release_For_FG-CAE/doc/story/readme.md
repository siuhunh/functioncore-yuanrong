
# SR 设计文档

元戎内核 SR 设计文档归档目录

归档要求:
+ 文档尽量以 SR 为粒度编写，在每个 AR 互相独立的情况下可以 AR 粒度编写，命名为 `SRID-SR描述`，例如 `SR-20210630-012-同一镜像支持所有语言.md`/`AR.20210519085956.001-nodejs runtime支持使用线程池方式执行请求.md`
+ 文档结构和内容参考 [./template.md](./template.md)， markdown 语法参考 [Markdown 教程](https://www.runoob.com/markdown/md-tutorial.html)/[入门教程](http://3ms.huawei.com/km/blogs/details/9895587?l=zh-cn)
+ 文档中的图片尽量使用 [cloudmodeling](https://cloudmodeling.tools.huawei.com/projectspace/detail/2928afd8ae624e609af7b0148bf05fad) 绘制后引用
    * 例如: [CPP-Runtime类图-Open Model](https://cloudmodeling.tools.huawei.com/projectspace/detail/2928afd8ae624e609af7b0148bf05fad?projectDiagramUUID=d973a16e07344fd193076d77f2ca1ae1&versionUUID=)
