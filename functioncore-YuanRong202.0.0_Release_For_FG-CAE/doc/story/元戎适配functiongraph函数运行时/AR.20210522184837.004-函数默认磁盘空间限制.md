# AR.20210522184837.004 函数默认磁盘空间限制

## Story 整体设计

### 功能描述
+ runtime容器对用户权限进行了限制，为了提供用户存放临时文件或者计算数据等场景的能力。
 用户有权限写/tmp目录，对默认磁盘空间/tmp目录进行如下配额限制

|  资源 | 默认值  |
| ------------ | ------------ |
| 临时磁盘空间（“/tmp”空间） | 512MB  |

+ 当检测到临时磁盘空间超过限制配额时删除 pod

### 场景分析
- 当前限制每个实例对/tmp目录有写权限，通过周期性（20ms）调用du命令查询/tmp目录大小，如果使用超过512M则删除POD。

### 方案详细设计
#### 方案设计
+ 函数默认磁盘空间限制流程图 ![AR.20210522184837.004-函数默认磁盘空间限制](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/qLo?t=1623849670548)
1. 通过定时任务周期性调用du命令查询/tmp目录大小
2. 若/tmp使用超过512M则杀掉对应runtime进程，并且标记isExceedMaxDiskSize = true
3. worker与runtime连接中断后，worker向runtime-manager发送请求，获取到runtime错误状态为超过默认磁盘空间限制
4. 将worker中未收到response的请求返回，错误信息为Exceed Max Disk Size!
5. 退出worker进程
