# 项目描述

元戎内核是基于函数计算的分布式并行开发框架，旨在构建开发效率与系统性能最佳平衡、线上线下一套架构的分布式应用开发框架，开创从烟囱式到积木式的架构级创新和根技术突破，帮助开发者定义分布式并行应用的开发和运行模式。

元戎内核期望创新性构建面向未来的分布式基础架构，在架构创新的基础上期望实现根技术的突破。围绕下一代集群硬件架构、基于对未来应用创新的趋势判断，构建面向集群硬件开发的“新”开发者生态，对下使能集群硬件，对上简化应用开发。

元戎内核将持续探索分布式根技术(大规模调度、数据一致性、低时延通信等)，应对和引领中间件&应用框架领域的快速变化，保持分布式领域的先进性。
