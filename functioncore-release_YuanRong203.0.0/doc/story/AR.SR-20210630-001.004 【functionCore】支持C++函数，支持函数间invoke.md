## Story 整体设计

### 功能描述
**背景说明**
KooMap项目上云，该项目相关算子均使用C++函数编写，为满足其需求需新增C++ runtime

**功能描述**  
1、提供C++编译指导说明及编译环境镜像
2、提供C++无状态函数互调的能力（算子不涉及有状态）

**用户体验**
1、用户可以根据提供的编译指导本地搭建编译环境，并完成代码的编译，输出对应的二进制文件
2、用户可以使用提供的编译镜像，通过docker run命令进入镜像完成编译
3、用户可以在函数中使用元戎函数互调的能力

### 场景分析
1、管理面前端界面新增C++运行时能力支持
2、用户需要手动指定函数入口文件，管理面将其写入元数据当中
3、剩余函数触发调用流程与其他语言一致

#### 方案设计
1、编译环境说明：

当前支持的C++版本为C++11
C++为编译型语言，由于当前环境中内置了平台SDK的动态库，用户函数包中无需上传，编译动态库使用的gcc版本为7.3.0，因此用户
在编译函数代码时也需要使用同版本的gcc，cmake的版本建议为3.14.2.

2、lib目录及include新增内容

3、目前黄区支持的C++ runtime为动态库.so的方式，FG目前初步决定采用的方式为二进制方式

4、函数互调只涉及无状态函数互调，有状态函数星图暂无需求，依据迭代进度进行开发考量

5、无状态函数互调接口：

auto f = new Function::Function(context, destFuncName);
auto objRef = f->Invoke(request);
std::string result = objRef->Get();
