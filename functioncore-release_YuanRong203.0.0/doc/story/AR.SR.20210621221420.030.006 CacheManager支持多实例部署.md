# AR.SR.20210621221420.030.006 CacheManager支持多实例部署

## Story 整体设计

### 功能描述
**背景说明**  
当前cache-manager为单实例部署，可靠性不足，需要改为多实例部署
**功能描述**  
cache-manager改为多实例部署，同时pod增加反亲和，保证pod尽量不部署在同一节点上
**用户体验**  
当一个cache-manager实例异常时，另一cache-manager实例仍能正常工作

### 场景分析
cache-manager支持多实例部署


### 方案详细设计

#### 方案设计
1. cache-manager的deployment.yaml中默认实例数改为2

2. cache-manager的deployment.yaml中增加pod反亲和策略

3. worker向具体哪一个cache-manager发送获取函数请求由k8s负责路由转发

4. cache-manager当前小代码未进行持久化（PRR需求添加），因此当一个cache-manager实例异常后，会导致两个实例中数据不一致。

NA
