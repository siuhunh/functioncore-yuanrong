## 2. 特性/功能实现原理

### 2.1 总体方案

#### 2.1.1 设计目标和原理

##### 2.1.1.1 设计目标

- **功能性：**在启动javaruntime的时候带上该参数

##### 2.1.1.2 设计原理

- func-JAVA_TOOL_OPTIONS - 在 Java 11 和 Java 8 上，支持这个环境变量来设置javaruntime中的额外命令行变量。这个环境变量允许你指定工具的初始化，特别是使用agentlib或javaagent选项启动本地或Java编程语言代理；

  `环境变量得命名与我们自己得保持一致`

***核心原理：***

**读取该环境变量，当有值时，重新拉起javaruntime进程。**

#### 2.1.2 方案概览

[JavaRuntime自定义启动参数](https://cloudmodeling.tools.huawei.com/myspace/diagram?diagramId=83155f4090dc4cc1a546ed900f6c271c)![JavaRuntime自定义启动参数](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/3PrU?t=1676344758419)

1. 特化一个包含javaruntime的实例；
2. 特化出来的实例读取环境变量JAVA_TOOL_OPTIONS并重新初始化javaruntime进程；
3. 发送执行函数的grpc请求到javaruntime；
4. javaruntime执行函数请求；
