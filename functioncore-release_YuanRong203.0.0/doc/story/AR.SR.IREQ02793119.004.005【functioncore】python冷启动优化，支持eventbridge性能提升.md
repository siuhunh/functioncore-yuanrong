## 【functioncore】python冷启动优化，支持eventbridge性能提升

关联AR:

+ AR.SR.IREQ02793119.004.005

### Story 整体设计

#### 功能描述

+ python-runtime启动时预加载requests包


#### 场景分析

+ 用户函数如果加载requests包，冷启动时延明显增大
+ requests包在初始化时会创建连接池，导致内存和时延增大
+ ![image-20220801101440027](C:\Users\d30015357\AppData\Roaming\Typora\typora-user-images\image-20220801101440027.png)

 

![image-20220801100458029](C:\Users\d30015357\AppData\Roaming\Typora\typora-user-images\image-20220801100458029.png)


#### 方案设计

+  python-runtime启动后立即导入requests包，在load,invoke用户函数前完成requests包的初始化
+  server.py文件完成requests包加载
+  128M暂不支持；多版本requests包冲突
