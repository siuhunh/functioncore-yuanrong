# 【functioncore】函数调用策略限制

## 1. 需求场景分析

### 1.1 特性需求来源与价值概述

forrest wave评测需要支持：函数调用策略限制（只公网、指定vpc等）

### 1.2特性场景分析

对数据面而言，函数配置了禁止公网访问后，用户函数实例不可以再访问公网

## 2. 特性/功能实现原理

### 2.1总体方案

数据面需要做的事情：
1. worker-manager需要能够根据管理面写的元数据信息解析新增的网络控制字段
2. worker需要判断是否需要关闭用户函数实例的公网访问能力，此能力仅对非VPC函数生效

### 2.2模块详细设计

*各模块的具体实现，包括模块的模块实现、对外接口定义、模块类设计*

1. 管理面：

管理面详细设计文档：
https://clouddevops.huawei.com/domains/551/wiki/8/WIKI2023010902139

函数元数据扩展新增：

```
NetworkController  NetworkController         `json:"network_controller" valid:",optional"`

type NetworkController struct {
	DisablePublicNetwork bool      `json:"disable_public_network" valid:",optional"`
	TriggerAccessVpcs    []VpcInfo `json:"trigger_access_vpcs" valid:",optional"`
}

type VpcInfo struct {
	VpcName      string `json:"vpc_name,omitempty"`
	VpcID        string `json:"vpc_id,omitempty"`
}
```

2. worker-manager：
在元数据中增加对上述字段的处理，并在特化时给worker传递是否关闭公网访问。

3.  worker:
在worker的VPC处理流程中，如果函数没有配置VPC，且需要关闭公网访问，则删除默认路由。集群内网络和节点网络有专门路由。

    例：用绿区route -n命令查询路由，特化前后对比：
    ```
    特化前：
    Kernel IP routing table
    Destination     Gateway         Genmask         Flags Metric Ref    Use Iface

    10.0.0.0        0.0.0.0         255.255.0.0     U     0      0        0 eth0
    169.254.169.254 10.0.0.81       255.255.255.255 UGH   0      0        0 eth0
    192.168.0.0     10.0.0.81       255.255.0.0     UG    0      0        0 eth0
    
    特化后：
    Kernel IP routing table
    Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
    10.0.0.0        0.0.0.0         255.255.0.0     U     0      0        0 eth0
    169.254.169.254 10.0.0.81       255.255.255.255 UGH   0      0        0 eth0
    192.168.0.0     10.0.0.81       255.255.0.0     UG    0      0        0 eth0
    ``` 

### 2.3 约束

#### 2.3.1上下游依赖需求

见 2.2 第一节 管理面。

#### 2.3.2其他约束

1. 关闭公网访问后，只能访问集群内网络。
2. 目前黄区部分环境pod默认路由和绿区不一样，建议不要在黄区测试此功能。
