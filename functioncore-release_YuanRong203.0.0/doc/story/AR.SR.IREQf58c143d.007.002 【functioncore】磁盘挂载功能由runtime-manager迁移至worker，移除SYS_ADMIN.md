# AR.SR.IREQf58c143d.007.002 【functioncore】磁盘挂载功能由runtime-manager迁移至worker，移除SYS_ADMIN

## 1. 需求场景分析

场景：为支持磁盘挂载功能，runtime容器配置了SYS_ADMIN权限，由于sudo二进制存在漏洞，用户函数可以利用此漏洞进行root提权，当用户函数进程拿到root权限后，结合SYS_ADMIN权限可以进行容器逃逸，存在安全风险

### 1.1 特性需求来源与价值概述

需求来源：星云实验室发现的数据面容器存在此capability，提出存在漏洞

价值概述：在正常业务功能不受影响的基础上，移除此capability，削减安全风险

### 1.2特性场景分析

1、特化过程中，通过worker容器进行磁盘挂载，worker已具备SYS_ADMIN权限
2、worker将磁盘挂载至与runtime新增的共享目录
3、在后续的特化过程中，runtime-manager创建用户指定目录，并将其软链至共享目录
4、移除runtime容器的SYS_ADMIN权限
5、/opt/function/runtime目录的只读权限是由remount实现，需要修改为初始化创建时指定只读权限

## 2. 特性/功能实现原理

1. InstanceManager 监听 ETCD，ETCD 元数据外部挂载文件字段信息示例如下：  


    "extendedMetaData": {
    	"mount_config": {
    		"mount_user": {
    			"user_id": 1001,
    			"user_group_id": 1001
    		},
    		"func_mounts": [
    			{
    				"id": "ccc6f799-96f9-4f47-9d67-ce4d267d90b9",
    				"mount_type": "sfs",
    				"mount_resource": "eb4ebf7a-db82-4602-82ce-7e1e57a8ef46",
    				"mount_share_path": "sfs-nas01.cn-north-7.ulanqab.huawei.com:/share-77644e2e",
    				"local_mount_path": "/home/fs",
    				"status": "active"
    			}
    		]
    	}
    }
    
2. InstanceManager 函数特化时封装请求包含外部挂载文件字段信息，发送到 worker。worker 通过 rpc 连接调用 runtime-manager 进行外部文件挂载。  
- 挂载前需要指定用户和用户组启动 runtime 进程
- 挂载前需要先进行 VPC 初始化，确保网络连接访问正常
- 创建本地挂载目录，权限赋值为 0750 ,将目录所属用户和用户组改为指定 uid、gid  
    本地路径页面限制为二级目录，且不能为已存在目录。
- 如果为 ECS 连接检查地址连通性和是否共享指定目录（nfs server 需要监听 111/20048 等端口用于检测）
- 通过 syscall.Mount() 方法挂载外部文件目录  
    func Mount(source string, target string, fstype string, flags uintptr, data string) (err error)

3. 以上连通性检查和mount动作执行转移至worker直接进行操作，挂载预共享目录/share

4. runtime-manager创建本地挂载目录，并将其软链至共享目录

### 2.3 约束

#### 2.3.2其他约束

本地挂载路径页面已经做了配置路径限制，不能为已存在目录，只能为二级目录且不能配置特殊字符 . 等。
