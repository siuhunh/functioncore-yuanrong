# AR.SR.fe530d03.003 支持对接IDE debug函数功能（nodejs）

## Story 整体设计

### 功能描述

**背景说明**  
IDE debug功能数据面适配对接，使cloud IDE的调试能力更加完善并且可视化

**功能描述**  
用户可以在cloud IDE进行函数的相关操作，通过debug插件反馈相关调试能力信息

**用户体验**  
用户可以在cloud IDE界面能够进行完整的函数创建、推送，并在函数间调用时展示调用链路

### 场景分析
debug的端到端体验需要管理面、数据面、依赖包共同完成
- 管理面：添加相关环境变量、部署相应依赖包 -- 夏嘉诚
- 数据面：感知到环境变量的配置，加载依赖包 -- 丁震
- 依赖包：在环境上部署host-agent，收集依赖包的产生信息，并反馈展示至cloud IDE前端 -- 陈亮

### 方案详细设计
数据流图 ![数据流图](https://cloudmodelingapi.tools.huawei.com/cloudmodelingdrawiosvr/d/11yw)

#### 方案设计
1. 当前融合版本中，函数特化时会将多余runtime进程杀掉，只保留特化的runtime进程，在此请求中，识别环境变量中的DEBUGGER_TAG，若正确识别则此函数为debug调试函数。

2. 读取剩余两个环境变量NODE_OPTIONS、MARS_OUTPUT。其中NODE_OPTIONS包含了依赖包的位置、以及相应的启动参数等，MARS_OUTPUT包含了插件产生信息的输出位置。

3. 当前元戎runtime容器中只有/tmp目录有用户写权限，因此插件信息输出目录只能指定为/tmp

4. 此demo流程中会将池化中预启动的nodejs进程删除，并将NODE_OPTIONS、MARS_OUTPUT加入新nodejs进程的启动环境变量中（重拉runtime进程）

#### 外部交互分析&&上下游依赖需求
添加相关环境变量、部署相应依赖包 -- 夏嘉诚
host-agent -- 陈亮
