# 调用运行信息

## Story 整体设计

### 功能描述
函数调用时返回实际内存占用。


### 场景分析
FunctionGraph 依据用户使用的函数实例内存规格进行计费参考。本需求在函数调用完成后，返回 runtime 的实际内存占用，供用户参考。

### 方案详细设计

#### 现状分析
FunctionGraph 的实现： 请求开始时，启动一个协程间隔 2ms 读取 '/sys/fs/cgroup/memory/memory.usage_in_bytes' （权限为 444 ）获取内存占用（包含 processrouter 进程和 runtime 进程），记录过程中的最大值，请求结束时停止 watch ，将 mem 占用大小随请求的 Summary 字段一路传回。

#### 方案设计
基本实现流程参考 FunctionGraph ，通过 runtime manager 进行采集，并将其传回给 worker 。
差异点为 YuanRong 支持函数实例多并发，因此不能简单的通过单个请求的结束，停止采集。需要判断当前请求数量为 0 时，清理保存的内存数据，待新请求到来时，重新开始记录。

流程：
runtime manager 自加载函数，清理其他 runtime 进程后，即开始定期上报内存信息，由 worker 控制是否更新内存信息。
